# Contributing

Open Language - English is open, and anyone can help improve it. The most useful help is a report of something wrong: an unnatural example, a wrong translation or an explanation that does not make sense.

## Who can help

- Learners can say where an explanation was unclear, or which topic they looked for and did not find.
- Native English speakers can check that the example sentences sound natural.
- German speakers can check that the translations are right.
- Teachers can review whether a page fits its level and teaches what learners need.

## Report a problem or ask for an article

Problems and requests go to the [issue tracker](https://github.com/OpenLanguageStudio/english/issues). Choose the form for a problem in an article, or the form to request an article, and fill in the page and what is wrong.

## Change a page

Each page is a Markdown file in the repository. A change is made as a pull request on GitHub. The content checks, `ol check`, run on every pull request, and a change is merged once they pass and a reviewer has read it.
