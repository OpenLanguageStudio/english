# AGENTS.md

The English coursebook for Open Language. Content only: articles in the level directories (`a1/` for now) at the top of the repository, built with the `ol` tools from the `open-language` package.

## Commands

- Install: `uv sync`
- Check everything: `uv run ol check`
- Check articles only: `uv run ol validate`
- Build the site: `uv run ol docs`
- List article templates: `uv run ol templates`

## Rules for changes

- Every article follows its category template. `ol validate` is the authority; if it fails, the article is not done.
- The rules a script cannot check are in the package's [authoring rules](https://github.com/OpenLanguageStudio/open-language/blob/main/docs/reference/authoring-rules.md). The questions a reviewer asks are in its review rubric, `ol/authoring/review-rubric.yml`. Read both before writing or reviewing an article.
- `.ol-validate-baseline` lists older articles that do not meet the templates yet. It only shrinks: fix an article, remove its line. Never add a line.
- The file name of a published article never changes. Links and listening tracks depend on it.
- No em dashes anywhere.
- Body text describes the language. It does not address the reader, except in admonitions and example translations.
- Previous and next links are generated by the build. Do not write them by hand.
- Example sentences in listening blocks are plain text only, with one translation line each.

## What this repository adds

- **Variety.** British English: *flat*, *colour*, *the bill*, *trousers*. Name the American word in a note where a learner will meet it often.
- **Translations are in German.** The language taught and the prose are both English, so every translation line, and the part after ` | ` in a `stack` cell, is German. The engine still calls this field "English" in places (`:title-en:`, the `Translation` entry in its `CONTEXT.md`); the translation language is an open design question, see the README.
- **English words in prose are in italics** when they are the words being taught (*is*, *a*, *the*), so they stand out from the explanation around them.
- **Grammar file names** are in English, as the language taught.
- **Model articles.** Grammar: `a1/grammar/the-verb-be.md`. Concepts: `a1/concepts/introducing-yourself.md`. Writing: `a1/writing/email-informal-1.md`. Vocabulary: `a1/vocabulary/in-the-kitchen-1.md`.
- **Presenters** live in the Open Language app only. `open-language.yml` holds none.
